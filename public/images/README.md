# Photos

The landing page (`/index.html`) references two photos here:

- `avatar.jpg` — small headshot for the masthead (shown at 24×24, square crop)
- `portrait.jpg` — the About-section portrait

Both currently use the same square headshot. To use a different (taller) crop
for the About section, replace `portrait.jpg` and update the `width`/`height`
attributes on its `<img>` tag in `index.html` to match the new dimensions.
